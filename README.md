# Workspace Projects

## W Comtismc — متجر إلكتروني للتجميل

متجر إلكتروني كامل لمنتجات التجميل والعناية.

```bash
cd WComtismc
dotnet run
```

افتح `http://localhost:5000`

### المميزات

- الصفحة الرئيسية مع منتجات مميزة وتصنيفات
- كتالوج منتجات مع بحث وفلترة وترتيب
- صفحة تفاصيل المنتج
- سلة تسوق
- إتمام الشراء والدفع
- تأكيد الطلب
- تسجيل دخول وإنشاء حساب
- سجل الطلبات

### التصنيفات

مكياج، العناية بالبشرة، عطور، العناية بالشعر، الأظافر
